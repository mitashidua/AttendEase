FIRST-TIME FIREBASE SETUP

Connect your Realtime Database.

Teachers, class rosters, one-time enrolled face templates, sessions and attendance are stored in Firebase Realtime Database. Firebase Storage is not required for this version.

You only need 2 things

1Realtime Database URL
2Service-account JSON

Keep the service-account JSON private. Do not commit it to GitHub. Student face templates and attendance are stored in your Firebase database.

Each teacher and class is logically separated inside the same Firebase project. A student enrolls once; future attendance only verifies the stored face templates.
